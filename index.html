The ant starts at the center of the grid. By default, it stops when it reaches an edge. The bright mint marker shows the ant’s position and direction.

At each step, the ant checks its current cell and the eight surrounding cells, then executes the actions of the first matching rule in order. Rules are not checked again during movement. See the bottom of the source code for copyright information.

Rule Reference

1. Cell Conditions (condition)

ant_cell_(location)=(color)
  • & to specify multiple conditions at once.
  • If multiple rules match, only the first rule in the list is executed.

2. Cell Locations (location)

Location numbers are fixed relative to the screen.

[2][3][4]
[5][1][6]
[8][7][9]

3. Define Colors (color)

setcolor (sign)=(Hex code)
setcolor B=#0000FF
  • (sign): a state symbol from A–Z
  • (Hex code): a hexadecimal color code in #RRGGBB format

4. Commands (order)

(1) paint (color)
Changes the cell where the ant ends up after movement to the specified state.

(2) paint_prev (color)
Changes the cell where the ant was standing immediately before the most recent movement command.

(3) Basic Movement Commands

  • straight: Move forward one cell in the current direction
  • right: Turn 90° right, then move one cell
  • left: Turn 90° left, then move one cell
  • flip: Turn 180°, then move one cell

(4) Multi-Cell Movement Commands
Add _n to a movement command to specify the distance (e.g., straight_2, left_3)

(5) Chaining Commands
; to chain multiple commands in sequence.

5. Rule Syntax

(condition) -> (order)

6. Multi-Cell Movement and Execution Timing

  • While a multi-cell movement command is running, rules are not checked on cells passed along the way.
  • The next rule is checked at the destination after movement is complete.
  • Therefore, no separate rules are executed on intermediate cells.
  • If a rule’s movement path crosses the boundary, the rule is not partially executed; the ant stops without applying movement or painting.

ant_cell_1=B -> straight; paint_prev A

ant_cell_1=C & ant_cell_7=E -> flip; paint_prev D

ant_cell_1=E & ant_cell_8=B -> left_2; paint_prev D

ant_cell_1=E -> right; paint_prev B

8. Background State (setbg)

setbg (sign)
setbg B
  • Sets the initial state of every grid cell to (sign). Use it only once; if omitted, the default is A.
  • Background cells are treated like any other cells, so rules for their state still apply. If the background is A, rules with an A condition can trigger.

9. Ant Starting Cell State (setstart)

setstart (sign)
setstart C
  • Sets the state of the cell where the ant starts to (sign). Use it only once; if omitted, it matches the background state.
